# Semana 02 — Formulário com CSS

Atividade de Desenvolvimento para Web (CEUMA). Versão estilizada do blog da Semana 01, com CSS incorporado no `index.html`: container do formulário, campos organizados com flexbox, botão com hover e foco visível, e nome e e-mail lado a lado em telas largas (bônus).

Para ver, abra o `index.html` no navegador.
